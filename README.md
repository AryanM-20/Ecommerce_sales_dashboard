# Ecommercre_Sales_Dashboard
1. Gala Stores Ecommerce Sales Dashboard: An interactive Power BI dashboard designed to analyze the sales performance of an e-commerce store. It provides a visual overview of sales, profit, quantity sold, customer purchases, and payment methods to help understand overall business performance.

2. Project Description / Purpose
The purpose of this project is to transform e-commerce sales data into meaningful visual insights that support better business understanding and data-driven decision-making. The dashboard enables users to explore sales performance across different states, product categories, customers, payment methods, and time periods.

3. Tech Stack
The dashboard was build using the following tools:
* Power BI Dashboard - Main data visualization platform used for report creation.
* Power Query - Data transformation and cleaning layer for reshaping and preparing the data.
* DAX (Data Analysis Expression) - Used for calculated measures, dynamic visuals, and conditional logic.

4. Features & Highlights
* Key Performance Indicators (KPIs): Displays total sales amount, quantity sold, profit, and Average Order Value (AOV).
* State-wise Sales Analysis: Compares sales performance across different states.
* Category Analysis: Visualizes product quantity distribution across categories such as Clothing, Electronics, and Furniture.
* Monthly Profit Analysis: Tracks monthly profit trends and highlights months with negative profit.
* Customer-wise Analysis: Compares sales across individual customers.
* Payment Mode Analysis: Examines the distribution of orders across COD, UPI, debit card, credit card, and EMI.
* Sub-category Profitability: Compares profit contributions from product sub-categories.
* Interactive Filters: Includes quarter and state filters for exploring specific segments of the data.

5. Key Business Insights
The dashboard helps users identify:
* States contributing the most to total sales.
* Product categories accounting for the largest share of quantity sold.
* Monthly variations in profitability, including loss-making months.
* Customers contributing significantly to sales.
* Preferred payment methods among customers.
* Product sub-categories generating higher profits.

6. Project Objective
This project demonstrates the use of business intelligence and data visualization to analyze e-commerce performance, identify trends, and present business data in an interactive and understandable format.

Project Type: Data Analytics / Business Intelligence
Domain: E-commerce
Visualization Tool: Microsoft Power BI
